Method

A score you can verify.

The fuzzy rules calculate the score. The neural network does not. The system cleans the message, finds keywords, measures four signals, fuzzifies them, applies 19 rules, and calculates one number. The result view shows each step.

  1. 01

    Clean the text

    The system decodes HTML entities and removes scripts and tags. It analyses only the visible body.

  2. 02

    Find keywords

    The system compares the body with the learned English and Serbian word lists. It calculates a keyword score from 0 to 10.

  3. 03

    Measure signals

    The system measures the keyword score, the number of links, the percentage of capital letters, and the punctuation rate.

  4. 04

    Fuzzify the signals

    Each signal receives a degree of membership in triangular or trapezoidal sets.

  5. 05

    Apply the rules

    Nineteen Mamdani rules combine the memberships with min and max. Each active rule limits its output set to its activation strength.

  6. 06

    Defuzzify and explain

    The system aggregates the limited sets with max. The centroid from 0 to 100 is the score. The category comes from the same value.

Measured signals

The system scores only the message body. The From and Subject fields give context. They do not go to the classifier.

Signal Definition Scale
Keywords The system looks for words in the selected learned word list. Each word has a weight. The system adds the weights of matched words and limits the sum to 10. 0–10
Links Unique URLs in the text or in href attributes. The count is limited to 10. 0–10
Capitals Uppercase letters divided by all letters. The system removes links first. 0–100%
Punctuation Exclamation marks and question marks divided by non-space characters. The result is multiplied by 100. 0–100%

Six output sets in three bands: 2 legitimate (0–22), 3 suspicious (22–72), 1 spam (72–100).

Function of the neural network

A neural network (NN) is a model with an input layer, hidden layers and an output layer. Each layer contains neurons. Each connection between neurons has a weight. A perceptron is a simple artificial neuron: it multiplies each input by a weight, adds the results, and passes the sum through an activation function.

The network learns these weights from labelled examples. It is trained offline on SpamAssassin data. It produces only the keyword lexicon: the weights in the two learned word lists.

The network does not see the four signals. It does not calculate the spam score. The fuzzy rules make the decision.

Rules and limitations

The system has 19 rules: 4 legitimate, 11 suspicious, and 4 spam. Each rule limits its output set to its activation strength. The system keeps the largest value at each point.

  • The four signals are designed for email. Scores for SMS and chat messages are not reliable.
  • Different emails can receive the same score when the fuzzy sets cannot separate them.
  • The boundaries of the fuzzy sets were calibrated on hand-labelled examples. All reported metrics come from held-out data.
  • The Serbian test set is partly machine-translated and partly synthetic.
